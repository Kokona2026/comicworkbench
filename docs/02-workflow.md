# 六阶段流程与验收门

每个阶段只有通过验收门才进入下一阶段。控制台「阶段流程」页实时显示每个门的检查结果，
数据来自 `app/studio.py` 对 `project/` 的实际扫描，不靠人工勾选。

## 总逻辑

| 阶段 | 输入 | 主要产出物 | 验收门 | 谁依赖它 |
| --- | --- | --- | --- | --- |
| 0 环境准备 | 本机配置、模型文件 | 能运行的 ComfyUI 和 Anima 模板 | 1024×1024 能稳定出图 | 阶段 1 |
| 1 角色设计 | 角色想法 | 设定表、主图、多视图、表情集（40–60 张候选） | 关键特征在所有图里一致 | 阶段 2、3–5 |
| 2 训练角色 LoRA | 筛选后的 20–40 张图和标签 | 角色 LoRA（挑出的 checkpoint） | 固定种子的测试网格里脸、发型、服装稳定 | 阶段 3–5 |
| 3 单张插画 | LoRA、构图想法 | 精修后的插画 | 手和脸无明显错误，与设定表一致 | 阶段 4、5 |
| 4 漫画页 | 分镜表、草图、LoRA | 排好版的漫画页 | 同一角色跨格可辨认，对话框不遮挡重点 | 成稿 |
| 5 动画短片 | 精修首帧 | 5 秒镜头，再拼接成片 | 角色脸不漂移，动作自然 | 成片 |

两条回退规则：

- 阶段 2 验收不过 → 回到阶段 1 补素材，或回到阶段 2 重训。
- 阶段 5 脸漂移 → 回到阶段 3 换首帧，或叠加角色 LoRA。

## 阶段 0：环境准备

1. 安装 ComfyUI 便携版并更新到最新。部分 Anima 社区版本对 ComfyUI 版本有要求
   （例如 2.9B 社区版要求 0.33.1 以上）。
2. 三个必需权重按下表放入 ComfyUI 的 `models/` 子目录（清单见
   `config/models.manifest.json`，`02-fetch-models.ps1` 会校验并打印缺失项的目标路径）。

   | 文件 | 放入目录 |
   | --- | --- |
   | `anima-base-v1.0.safetensors` | `models/diffusion_models` |
   | `qwen_3_06b_base.safetensors` | `models/text_encoders` |
   | `qwen_image_vae.safetensors` | `models/vae` |

3. 用 ComfyUI Manager 安装常用节点包：ComfyUI-GGUF、KJNodes、VideoHelperSuite
   （视频阶段）、Impact Pack（FaceDetailer 修脸）。
4. `scripts\00-init-project.ps1` 建立 `project/` 六个目录。
5. `python tests\smoke_test.py` 跑一张 1024×1024，记录耗时与显存 →
   写入 `reports/baseline.json`，作为之后对比的基线。
6. 显示器接到主板核显接口，让 5070 Ti 的显存全部留给 AI。

**验收**：模板图正常生成、没有报错，并记录了基准耗时。

> 许可提醒：Anima 模型卡标注的是 CircleStone Labs 的非商业许可，
> 商用前请先核对许可条款。

## 阶段 1：角色设计

1. **写设定表** —— `project/00_bible/character.json`，字段见下。之后每次出图都从这张表
   复制，不凭记忆重写。控制台「提示词」页可直接用设定表填充模板。

   | 字段 | 怎么写 |
   | --- | --- |
   | `trigger` | 自拟唯一词，例如 `char_aya` |
   | `hair` | 长度、颜色、刘海、发饰，如 `long hair, blue hair` |
   | `eyes` | 如 `blue eyes, tareme` |
   | `outfit` | 主服装款式与配色 |
   | `signature` | 泪痣、发夹、疤痕；越小越要写 |
   | `body` | 体型与年龄感，一句话 |
   | `personality` | 默认表情与性格 |
   | `palette` | `main` / `accent` / `sub` 三色 |

2. **出主图** —— 标签顺序：质量 → 元数据 → 年份 → 安全标签 → 人数/角色名/作品名/画师
   → 一般标签。小写、空格分隔，只有 score 标签用下划线。1MP 左右、30–50 步、
   CFG 4–5、`er_sde`，一次 16 张，选定后记下种子。
3. **出多视图** —— 不要把 `front view, side view, back view` 塞进同一条提示词，
   模型会把它们当风格词。每个视角单独出图。侧面和背面容易崩，可用 Illustrious 加
   姿势/线稿 ControlNet，或用 Qwen-Image 2.1 以主图做编辑（先说保持什么，
   再锁定构图，最后只说一个改变）。
4. **出表情集** —— 固定半身、同一背景，只改表情标签，6–8 种。
5. **对照筛选** —— 并排逐项对照设定表。错位的发饰、多余的手指会被 LoRA 学进去，
   宁缺毋滥。

**验收**：保留 40–60 张候选，发型、瞳色、服装配色、标志性特征每一项都对得上设定表。

## 阶段 2：训练角色 LoRA

1. **筛选数据集** —— 全身、半身、特写都要有；视角和表情要有变化；背景不要全部相同。
   手崩、服装细节不一致、构图重复的图直接剔除。
2. **打标** —— WD14 自动打标后删掉固定特征标签（发型、瞳色、默认服装），
   让 LoRA 从像素学；触发词放最前，保留表情、动作、视角、背景这些会变的标签。
   控制台会检查「标签以触发词开头」。
3. **训练参数** —— 见 [04-parameters.md](04-parameters.md)。步数以样图为准，不以数字为准。
4. **测试网格** —— 每个 checkpoint × 3 个固定种子 × 5 条提示词 × 强度 0.6/0.8/1.0。
5. **挑 checkpoint** —— 选最早就能稳定保持特征的那个，更晚的容易把姿势和背景一起锁死。
   选定结果写入 `project/02_lora/selected.json`。

**验收门**（全部通过才进阶段 3）：三种强度下脸型稳定 / 换装换场景不被锁死 /
侧面背面不崩 / 不同种子下特征一致 / 换背景时背景不被带偏。

## 阶段 3：单张插画

1. 构图随意 → 直接文生图；姿势必须精确 → 先画草图再用 ControlNet
   （严格姿势走 Illustrious，局部重绘走 Anima LLLite inpainting）。
2. 提示词标签与自然语言可混用；自然语言至少两句，过短容易出现意外结果。
3. 1MP 左右、30–50 步、CFG 4–5、LoRA 0.8–1.0，一批 8–16 张。
4. Krita 局部重绘修手、脸、饰品；denoise 从 0.3–0.5 起试，一次只改一个区域，每步新建层。
5. 放大：先 2–3 倍，再低 denoise（0.2–0.35）分块重绘。
6. 换装变体用 Qwen-Image 2.1 的 Image Edit 模板，每张变体都要对照检查。

**验收**：手、脸、饰品无明显错误；发色瞳色与标志特征一致；无多余文字水印；放大无接缝。

## 阶段 4：漫画页

1. 先写分镜表 `project/04_manga/storyboard.json`（`panels` 数组，每格含
   `panel` / `shot` / `character` / `expression` / `dialogue` / `camera` / `control`），
   再去出图。
2. 空镜氛围 → 文生图；姿势精确 → 草图 + ControlNet；只改局部 → inpainting；
   多角色 → 各自出图再合成。Anima 的线稿/深度/姿势 ControlNet 目前是实验性权重，
   姿势控制偏弱，严格姿势交给 Illustrious。
3. 逐格提示词用「固定头 + 变量」：不要写含糊的「同一个女孩」，
   要在每个重要提示词里重复核心特征。
4. 横格 1152×896，竖格 896×1152，保持 1MP 左右，不要为贴合格子硬拉极端比例。
5. 黑白稿：提示词加 `monochrome, greyscale` 出灰度，或出彩色后在排版软件去色加网点。
   先各做一格小样再选。
6. 排版后把整页缩成缩略图，看角色能否一眼认出。

**验收**：缩略图里跨格可辨认 / 对话框不遮挡脸和重点 / 阅读顺序清楚 / 各格画风与线宽接近。

## 阶段 5：动画短片（可选）

> **当前排期：暂时搁置。** 本节内容、`config/workflows/wan22-i2v.json` 与
> `params.wan_i2v` 都保留，随时可以接回来；只是控制台把该阶段标为「暂缓」，
> 创作页不再列出视频模板，阶段也不参与阻塞判断（本就是可选阶段）。
> 恢复时把 `config/ui.json` 的 `video.paused` 改为 `false` 即可。

1. 选脸清晰、周围留运动空间的画面作首帧，缩放到 832×480（横）或 480×832（竖）。
2. Wan 2.2 I2V A14B GGUF + lightx2v 4 步蒸馏 LoRA；需要 ComfyUI-GGUF、KJNodes、
   VideoHelperSuite。
3. 81 帧 ≈ 5.06 秒，CFG 1（蒸馏版不需引导，负向留空），Shift 5.0，Euler + simple。
   4 步和 8 步都在本机各测一次 —— 有测试发现某些显卡上 4 步反而更慢。
4. 动作提示词只写动作、表情变化、镜头运动、环境动态，一段一两个动作。
5. 每首帧生成 4–8 条抽卡。
6. 长镜头接力：取上一段尾帧作下一段首帧；多次接力会漂移，补救办法是叠加角色 LoRA、
   缩短单段、或用带参考图的扩展节点。
7. 后期：RIFE 插帧 → 二次元超分 → ffmpeg 拼接 → 配音剪辑。

**验收**：脸全程不漂移 / 动作自然无肢体崩坏 / 相邻片段尾帧与首帧能衔接。
